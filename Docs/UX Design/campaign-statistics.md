# UX Brief: Campaign statistics

**Job:** On one campaign, answer “is this working?” in five seconds.

**Lives on:** Campaign detail — headline tiles at the top, deeper breakdowns below or behind the same page.

## How it works

1. Open a campaign.
2. Read top-level tiles (sent, opens, replies, positives) for the campaign’s life or a chosen range.
3. Optionally open lead / mailbox / date breakdowns on the same page — not a different product.
4. Jump to the lead or mailbox that is dragging the numbers when a row asks for it.

## Hard rules

- Reuse Dashboard/Reports tile language — nothing new to learn.
- Top tiles stay filter-free; range is the only control.
- Campaign-scoped only; workspace rollups stay in Analytics.

## Do not build

- A “Campaign analytics” nav item.
- Parallel chart packs that duplicate Reports.
- Export UIs that belong on the leads export action.
