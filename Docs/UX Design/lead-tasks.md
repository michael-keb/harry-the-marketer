# UX Brief: Lead tasks

**Job:** Turn something just read into a human follow-up without leaving the thread.

**Lives on:** Inbox thread + Dashboard Action Center (where parked human work already lives). Optional marker on a pending draft.

## How it works

1. From a thread, create a task in a few seconds (title/due/assignee as light fields).
2. Task appears on the lead and in Action Center — same work, two entry points.
3. Complete/cancel from Action Center or lead; trail keeps history (cancel preferred over hard erase when implemented that way).

## Hard rules

- No separate Tasks page that splits human work across two apps.
- Tasks are for humans; they do not send mail.

## Do not build

- Tasks nav item.
- Project-management features (boards, sprints, deps).
